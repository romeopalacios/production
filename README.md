# ThirdRoad Productions — Mock Website

A sleek, editorial-style mockup for a writing and producing company focused on film and television.

## Open in VS Code

1. Unzip this folder.
2. Open the `thirdroad-productions` folder in VS Code.
3. Open `index.html`.
4. If you use the Live Server extension, click **Go Live**.

## Files

- `index.html` — page content
- `styles.css` — all visual styling
- `script.js` — mobile menu, scroll reveals, current year

## Important

The projects and some supporting copy are placeholders for presentation purposes.
Replace them with ThirdRoad Productions' actual credits, projects, team information,
contact details, and development slate before publishing a real site.

The visual direction intentionally avoids film-production clichés and focuses on
writing, producing, development, and material acquisition.
